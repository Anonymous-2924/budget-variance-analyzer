# 📊 Budget Variance Analyzer

An AI-assisted financial analytics application that helps businesses analyze budget versus actual spending, identify variances, and make data-driven decisions.

🔗 **Live App:** [Try Budget Variance Analyzer](https://budgetvarianceanalyzer.streamlit.app/)

## 📌 Overview

Budget Variance Analyzer simplifies financial analysis by allowing users to upload CSV or Excel files and turn raw financial data into meaningful insights. It combines automated data preparation, financial calculations, interactive visualizations, and AI-powered question answering in one application.

## ✨ Key Features

- **Data Understanding:** Explore dataset structure, data types, missing values, and duplicates.
- **Automated Data Cleaning:** Clean whitespace, convert numeric text, and detect duplicate records.
- **Financial Analysis:** Analyze overall performance, budget vs. actual spending, category performance, and trends.
- **Interactive Visualizations:** Explore financial performance through dynamic charts.
- **AI-Powered Q&A:** Ask natural-language questions about uploaded data using Groq API and OpenAI GPT-OSS 20B.

## 💼 Business Use Cases

- **FP&A Teams:** Monitor budget performance and identify spending deviations.
- **Finance Managers:** Track overspending and review departmental performance.
- **Business Analysts:** Analyze financial trends and prepare insights.
- **Department Heads:** Compare planned budgets with actual expenditure.
- **Management Reporting:** Support faster, data-driven financial reviews.

## ⚙️ Tech Stack

Python · Streamlit · Pandas · Plotly · OpenPyXL · Groq API · OpenAI GPT-OSS 20B

## 🚀 How It Works

1. Upload a financial CSV or Excel file.
2. Understand and prepare the data.
3. Select the required financial analysis.
4. Explore metrics and interactive charts.
5. Ask questions about the dataset in natural language.
